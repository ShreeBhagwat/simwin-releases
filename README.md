# SimWin releases

Signed and notarized builds of **SimWin**, the Mac app by Codeaamy Private Limited. Website: https://simwin.dev

This repository holds release files only (SimWin's source is not here):

- `download/`: the newest DMG, its SHA-256 and the Sparkle update feed. simwin.dev serves them as
  `https://simwin.dev/download/SimWin.dmg` and `https://simwin.dev/download/appcast.xml` (proxied to this repository's GitHub Pages site).
- Releases: every version, with release notes.
- `licenses/`: third-party notices and the Wine source offer.

Install: `curl -fsSL https://simwin.dev/install.sh | bash`, or download from https://simwin.dev.
