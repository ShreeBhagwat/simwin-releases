# SimWin releases

Signed and notarized builds of **SimWin**, the Mac app by Codeaamy Private Limited.

- Download the newest version: https://simwin.dev/download/ (or the latest release on this page).
- SimWin updates itself (Sparkle) from `https://simwin.dev/download/appcast.xml`, which this repository serves via GitHub Pages.
- Third-party notices and the Wine source offer: [`licenses/`](licenses/).

This repository holds releases only; SimWin's source is not here.
