Privacy

SimWin privacy

Short version: SimWin has no analytics, no tracking and no account. Your code stays on your Mac.

Last updated: 27 October 2026. SimWin is made by Codeaamy Private Limited, Pune, India.

What SimWin connects to

  • GitHub, during setup, to download its build tools and Wine. The exact files and their checksums are listed by simwin components.
  • Google’s Flutter download server (storage.googleapis.com), the first time you build with a Flutter version, to fetch that version’s Windows engine files. This is the same server the Flutter tool itself uses.
  • simwin.dev and GitHub, once a day, to check for updates (Sparkle). The request includes SimWin’s version, as any download does, and nothing about you or your projects.

These services see your IP address, as with any download. SimWin sends nothing else, and nothing to us. The apps you run in SimWin can of course make their own network requests.

Your projects

SimWin builds from a copy of your project in ~/Library/Caches/SimWin on your Mac. Your code is never uploaded anywhere.

Problem reports

If you report a problem, you send it yourself, from your own mail app or GitHub account. The diagnostics file contains versions, setup checks and SimWin’s logs, never your source code, with your home folder shortened to ~. We use reports only to fix problems, and you can ask us to delete them.

This website

This site has no cookies, analytics or tracking. It is hosted on GitHub Pages, which keeps standard server logs.
